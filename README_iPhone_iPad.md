# PodoTriage — version iPhone / iPad

Cette version est une PWA (Progressive Web App), pensée pour Safari sur iPhone/iPad.

## Installation sur iPhone/iPad

Pour que l'installation comme application fonctionne correctement, les fichiers doivent être servis par un petit hébergement web HTTPS.

Une fois l'URL ouverte dans Safari :
1. Touchez le bouton Partager.
2. Choisissez « Sur l’écran d’accueil ».
3. Touchez « Ajouter ».

L'application s'ouvrira ensuite depuis l'écran d'accueil en mode autonome.

## Important

Cette version reste un prototype clinique.
Elle ne doit pas être utilisée telle quelle pour stocker des données de santé identifiantes en production.
Les règles intégrées servent à orienter un praticien et ne constituent pas un diagnostic définitif.
